# 🧾 AI Vision Chatbot for ATM Receipts

A smart assistant that analyzes ATM receipts and transaction slips from images to explain response codes in simple language. Ideal for enhancing financial literacy, customer clarity, and accessibility.

---

## 🚀 Key Features

- 🖼️ **Image Upload**: Analyze ATM receipts, slips, and error printouts via image input
- 🔍 **Auto Detects ATM Codes**: Identifies printed response/error codes on the receipt
- 🧠 **LLM-Powered Explanations**: Uses LLaMA 3.1 via Groq to explain codes clearly
- 👴 **Designed for Accessibility**: Helps elderly and non-technical users understand outcomes
- 🌐 **Multiplatform Deployment**: Can be deployed in ATM centers, mobile apps, or kiosks
- 🔁 **Interactive Chat History**: Tracks ongoing Q&A about uploaded images
- 👓 **Supports the Visually Impaired**: Ideal for screen readers with voice-to-text integration

---

## 🧠 Tech Stack

- **Streamlit** for UI
- **Groq + LLaMA 3.1** for LLM response
- **Base64 image encoding** for secure image transmission
- **Session state** for conversation management
